# Suggested demonstration

1. Log in as admin@mail.apu.edu.my / admin123@. View users, achievements, reports and audit logs. Create a test student, change permissions, and check its login.
2. Log in as coordinator@mail.apu.edu.my / coordinator123@. Create/edit a challenge, campaign and announcement. Use a real uploaded submission to test Approve, Needs revision and Reject. Check the popup and returned list.
3. Log in as computing.rep@mail.apu.edu.my / faculty123@. Feature a challenge, create a faculty activity, create a faculty announcement and submit a report with an attachment. Sign in as engineering.rep@mail.apu.edu.my to check faculty separation.
4. Log in as tp900001@mail.apu.edu.my / TP900001123@. This Computing account shows its highest earned level for each badge family. Compare tp900003@mail.apu.edu.my / TP900003123@ to see different progress. Historic activity now also contributes points and progress.
5. Register a fresh student with an unused TP number to test the complete join/upload/review/reward flow. Imported students may have reached a challenge's three-submission limit.
6. Review leaderboards and collective faculty achievements after approvals. Try accessing another role's URL and another student's evidence; access should be blocked.

Sample physical waste weight and CO2 values remain unmeasured because the project has no conversion factors. Activity counts and point totals come from saved records.
